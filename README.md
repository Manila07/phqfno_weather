# Noise-Aware PHQFNO for Shallow-Water Surrogate Modelling

## Objective

This project investigates a hybrid quantum-classical Fourier neural
operator for predicting 2-D shallow-water dynamics under simulated
quantum-circuit noise.

## Current status

- [x] Qiskit installed
- [x] Ideal Bell-state simulation
- [x] Noisy Bell-state simulation
- [ ] Trainable Qiskit quantum layer
- [ ] Classical FNO baseline
- [ ] PHQFNO prototype
- [ ] Qiskit Aer noise study
